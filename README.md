# Zipbanchan Responsive Renewal

집반찬연구소 커머스 화면을 PC와 Mobile 기준으로 재구성한 반응형 웹 리뉴얼 프로젝트입니다.  
상품 탐색, 메인 배너, 카테고리, 상세 페이지 흐름을 반응형 구조로 정리하고 Swiper 기반 인터랙션을 적용했습니다.

## Live Demo

https://chlghdwns960-wq.github.io/zipbanchan-responsive-renewal/

## Role

- PC / Mobile 반응형 레이아웃 설계
- 커머스 메인 화면 및 상세 화면 구현
- Swiper 기반 배너 및 상품 영역 인터랙션 적용
- 상품 탐색 밀도와 구매 흐름을 고려한 화면 재구성
- GitHub Pages 배포

## Tech

- HTML5
- CSS3
- Vanilla JavaScript
- Swiper
- AI-assisted workflow

## Key Points

- PC에서는 상품 탐색 밀도와 레이아웃 안정성 강화
- Mobile에서는 빠른 탐색과 구매 흐름 중심으로 구조 정리
- 메인 배너, 상품 카드, 상세 페이지의 시각 흐름 정리
- 가로 스크롤 및 배너 위치 문제를 수정하며 화면 안정성 개선

## Portfolio Note

이 프로젝트는 기존 커머스 화면을 반응형 기준으로 다시 구성하는 데 초점을 둔 작업입니다.  
면접에서는 PC와 Mobile에서 레이아웃 기준을 어떻게 다르게 잡았는지, 상품 탐색 흐름을 어떻게 정리했는지 설명할 수 있습니다.
