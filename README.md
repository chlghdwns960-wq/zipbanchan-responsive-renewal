# Zipbanchan Responsive Renewal

집반찬연구소 커머스 화면을 PC와 Mobile 기준으로 재구성한 반응형 웹 리뉴얼 프로젝트입니다.

https://chlghdwns960-wq.github.io/zipbanchan-responsive-renewal/

## Original Demo

## Role

- PC·Mobile 반응형 구조 설계
- 커머스 메인/상세 화면 구현
- UI 인터랙션 적용
- 상품 탐색과 구매 흐름 재구성

## Tech

- Vanilla JavaScript
- Swiper
